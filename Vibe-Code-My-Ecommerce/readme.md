# SnapPlay — Photography & Gaming Marketplace

แพลตฟอร์ม E-Commerce ที่รวบรวมบริการ 3 ประเภทในที่เดียว:
- **📸 จองช่างภาพ** — เลือกช่างภาพจากผลงาน ดูตารางว่าง จองสะดวก
- **🔭 เช่าเลนส์** — เช่าเลนส์ราคาแพง คำนวณราคาตามวันที่เช่า
- **🎮 ซื้อเวลาสตรีมเมอร์** — เลือกสตรีมเมอร์ ดูแพ็กเกจ จองเวลาเล่นเกม

---

## โครงสร้างโปรเจกต์

```
Vibe-Code-My-Ecommerce/
├── web/                      # Frontend (HTML + CSS + JS)
│   ├── index.html            # หน้าแรก
│   ├── photographers.html    # หน้ารายชื่อช่างภาพ
│   ├── streamers.html        # หน้ารายชื่อสตรีมเมอร์
│   ├── lenses.html           # หน้ารายการเลนส์ให้เช่า
│   ├── login.html            # หน้าเข้าสู่ระบบ
│   ├── register.html         # หน้าสมัครสมาชิก
│   ├── booking.html          # หน้าจอง/เช่า/ซื้อ
│   ├── my-bookings.html      # หน้าการจองของฉัน
│   ├── css/
│   │   └── style.css         # แต่งหน้าตาเว็บ
│   └── js/
│       ├── data.js           # ข้อมูลตัวอย่าง (ช่างภาพ, สตรีมเมอร์, เลนส์)
│       └── auth.js           # ระบบล็อกอิน/สมัครสมาชิก (ใช้ localStorage)
├── apps/
│   └── api/                  # Backend API (Express + MongoDB) — เผื่อใช้ทีหลัง
├── readme.md
└── .gitignore
```

---

## วิธีเปิดเว็บ

แค่เปิดไฟล์ `index.html` ในเบราว์เซอร์ (ดับเบิ้ลคลิก)
หรือใช้ Live Server ใน VS Code ก็ได้

**ข้อมูลทั้งหมดถูกจำลองไว้ใน `js/data.js`** ไม่ต้องใช้ฐานข้อมูลก็ดูได้เลย
